<div class="fp"><b>第一性原理</b>　Herpesviruses（CMV、EBV、HHV-6、HSV、VZV）、Toxoplasma、TB、HBV 都是<b>終生潛伏</b>的病原，平常靠 <b>pathogen-specific T cell</b> 壓住；移植讓 T cell 歸零，所以再活化是「受者血清狀態 × T cell 恢復速度（TCD、ATG、haplo、cord、GVHD／類固醇）」的函數。策略因此只分三種：<b>有安全藥 → 預防</b>（acyclovir、letermovir、TMP-SMX、HBV 核苷）；<b>藥有毒 → PCR 監測＋preemptive</b>（GCV 傷骨髓、foscarnet／cidofovir 傷腎）；<b>治本是 T cell 回來</b>（減 IS、virus-specific T cell）。EBV 住在 B cell → 可以用 rituximab 拔掉它的家。</div>

## MECE 分岔

| 層 | 問什麼 | 分支（互斥、窮盡） | 決定了什麼 |
| --- | --- | --- | --- |
| 1 預防策略 | 有沒有安全有效、可長期吃的藥？ | 有 → universal prophylaxis（HSV/VZV、CMV R+、PJP、Toxo、HBV）；沒有但 PCR 可預警 → 監測＋preemptive（CMV 停 letermovir 後、EBV、ADV）；都沒有 → 症狀時診斷（HHV-6、BK、呼吸道病毒） | 監測頻率：高危每週 |
| 2 狀態 | Infection（PCR 陽性）或 end-organ disease？ | Infection → preemptive；disease（需組織或 BAL 證據）→ 全劑量治療＋處理器官 | CMV pneumonitis、GI 要切片 |
| 3 治療失敗 | 臨床失敗還是基因抗藥？ | Refractory：適當劑量 ≥2 週病毒量升 >1 log10（臨床定義）；resistant：測到 UL97／UL54／UL56 突變 | Refractory 先排劑量不足與 IS 過重；resistant 依突變換藥 |
| 4 治本 | T cell 能不能回來？ | 能 → 減 IS；不能 → virus-specific T cell（CMV、EBV、ADV、BK；donor 或 third-party）、DLI | 抗病毒藥只是爭取時間 |

## 速記：CMV

| 項目 | 重點 |
| --- | --- |
| 風險 | <b>R+</b> 最高；R+／D− 在 TCD／MAC 下更差（donor 無 CMV 免疫） |
| Letermovir | <b>R+ allo-HCT</b> 預防至 D+100，高危延長至 D+200；480 mg QD（併 CsA 240 mg）；UL56 terminase，無骨髓毒性；不蓋 HSV/VZV → 續 acyclovir |
| 監測 | 每週 CMV PCR 至少到 D+100，有 GVHD／停預防後延長 |
| Preemptive 門檻 | 依中心與風險（無統一 IU/mL），看絕對值與上升速度 |
| 藥物 | GCV 5 mg/kg q12h（valGCV 900 mg BID）→ 骨髓；foscarnet 90 mg/kg q12h → 腎、電解質（植入前或 cytopenia 選它）；cidofovir 三線 |
| Disease | GI 最常見；pneumonitis 致死率高（可加 IVIG，證據有限）；retinitis 少 |
| R/R | <b>Maribavir</b> 400 mg BID（UL97 kinase）：SOLSTICE 第 8 週清除 56% vs 24%；FDA 2021；不可併 GCV（拮抗） |

## 速記：其他病毒

| 病毒 | 預防／監測 | 治療 | 要點 |
| --- | --- | --- | --- |
| EBV／PTLD | 高危（ATG、alemtuzumab、TCD、haplo／cord、二次移植）每週 EBV DNA ≥4 個月 | 病毒量上升 → rituximab 375 mg/m² 每週 1–4 劑；PTLD：rituximab＋減 IS → EBV-CTL（<b>tabelecleucel</b>，EMA 2022）→ 化療／DLI | 多為 donor B cell、<1 年；rituximab 進不了 CNS |
| HHV-6 | 不常規監測 | Encephalitis（cord 多、近事失憶、SIADH）→ foscarnet 或 GCV | ciHHV-6：全血病毒量恆高，不治療 |
| ADV | 高危兒童、haplo／TCD 每週血 PCR | Cidofovir＋probenecid＋水化；減 IS、ADV-CTL | 肝炎、肺炎、腸炎、HC |
| BK | 不篩 | Hemorrhagic cystitis：水化、膀胱灌洗、輸血小板；cidofovir 證據弱（見 16 頁） | 早期 HC＝Cy acrolein |
| 呼吸道病毒 | 移植前有症狀延後；家屬員工打流感疫苗 | 流感 oseltamivir（>48 h 仍給）；RSV 高 ISI → ribavirin；COVID：remdesivir、nirmatrelvir/r（CNI DDI） | 目標：阻止 URTI → LRTI |
| HBV | HBsAg+ → entecavir／tenofovir 至停 IS 後 ≥12–18 個月；anti-HBc+ → 預防或每月 HBV DNA | 再活化 → 核苷類 | Donor HBsAg+ 先治 donor |
| HSV／VZV | Acyclovir／valacyclovir 至少 1 年且至停 IS | VZV 內臟型可先腹痛、肝炎再出疹 | RZV 疫苗可用 |

## 速記：Toxo、TB、PJP

| 病原 | 預防 | 治療／要點 |
| --- | --- | --- |
| Toxoplasma | R+ allo：TMP-SMX；未用 TMP-SMX 者每週血 PCR | Pyrimethamine＋sulfadiazine＋folinic acid；腦炎、肺炎、播散 |
| TB | 病史、CXR、IGRA（淋巴球低偽陰性）；LTBI：isoniazid 6–9 個月 | Rifampicin 大降 CNI → rifabutin 或調劑量 |
| PJP | TMP-SMX 從植入後，≥6 個月且至停 IS；替代 atovaquone、dapsone（G6PD）、pentamidine | 同時擋 Toxo、Nocardia；注意骨髓抑制、高 K（併 CNI） |

| 題 | 一開口就講 |

| 病毒總論 | 「潛伏病毒靠 T cell 壓，我分預防、監測＋preemptive、有症狀才治三種，治本是讓 T cell 回來。」 |

## 容易被電

- Letermovir 只給 D−/R+：對象是所有 R+ allo-HCT。
- Letermovir 期間停 acyclovir：它不蓋 HSV/VZV。
- 把 refractory 等同 resistant：refractory 是臨床定義，resistant 要基因型。
- HHV-6 PCR 很高就治療：先排 ciHHV-6，無症狀 viremia 不治。
- 潛伏 TB 用 rifampicin 短療程：與 CNI／azole 嚴重交互作用。
