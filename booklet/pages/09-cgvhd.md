<div class="fp"><b>第一性原理</b>　cGVHD 不是「拖久的 aGVHD」，是另一種病：胸腺被 conditioning／aGVHD 打壞 → <b>負選擇與 Treg 失效</b> → 自體／同種反應的 <b>T cell＋B cell</b>（BAFF↑、自體抗體）持續活化 → <b>macrophage（CSF-1R）＋TGF-β 驅動纖維化</b>。三期：①發炎損傷 → ②慢性免疫失調 → ③異常修復＝纖維化。所以：發炎期可逆、要全身治療；纖維化（硬皮、BOS、攣縮）只能止住，靠局部與復健；二線藥物各打一環。表現像自體免疫病（lichen planus、scleroderma、Sjögren、PBC、BO）。</div>

## MECE 分岔

| 層 | 問什麼 | 分支（互斥、窮盡） | 決定了什麼 |
| --- | --- | --- | --- |
| 1 診斷 | 有沒有 NIH 2014 <b>diagnostic</b> sign？ | 有 → 直接成立；只有 <b>distinctive</b> sign → 需同器官或他器官切片／檢查（Schirmer、PFT、影像）佐證；都沒有 → 不是 cGVHD（皆須排除感染、藥物、腫瘤） | Diagnostic 例：皮膚 poikiloderma／lichen planus-like／sclerosis／morphea、口腔 lichen planus-like、食道 web／stricture、筋膜炎、生殖器 lichen sclerosus、切片證實 BO；distinctive 例：乾眼、口乾／潰瘍、指甲 dystrophy、色素脫失、myositis |
| 2 嚴重度 | NIH global severity？ | Mild／moderate／severe（見下表） | Mild → 局部；moderate–severe → 全身 |
| 3 對類固醇 | 反應如何？ | 有反應 → 數月慢減；SR；steroid-dependent；intolerant | 第 4 層 |
| 4 二線打哪一環 | 卡在哪一期？ | T cell 訊號：ruxolitinib、sirolimus、ECP；B cell：ibrutinib（BTK／ITK）、rituximab；Th17/Treg＋纖維化：belumosudil（ROCK2）；macrophage 纖維化：axatilimab（CSF-1R） | 依器官、共病、藥物交互作用選；無頭對頭比較 |

## 速記：嚴重度與定義

| 項目 | 切點 |
| --- | --- |
| 器官 score | 8 器官（皮膚、口、眼、GI、肝、肺、關節筋膜、生殖道）各 0–3 |
| Mild | 1–2 器官、最高 score 1、肺 0 |
| Moderate | ≥3 器官 score 1，或任一器官 score 2，或肺 score 1 |
| Severe | 任一器官 score 3，或肺 score 2 |
| 肺 score（FEV1） | 1：60–79%；2：40–59%；3：≤39%（BOS 診斷見 16 頁） |
| SR | Pred ≥1 mg/kg/d ≥1 週惡化，或 ≥0.5 mg/kg/d ≥4 週無改善 |
| Steroid-dependent | 兩次減量（間隔 ≥8 週）都無法降到 0.25 mg/kg/d 以下 |
| 危險因子 | 先前 aGVHD（最強）、PBSC、女給男、HLA mismatch／URD、年齡、無 ATG／PTCy、DLI |
| Onset | Progressive（aGVHD 直接延續，最差）／quiescent／de novo |

## 速記：治療

| 情境 | 處置 | 依據 |
| --- | --- | --- |
| First-line | Pred 1 mg/kg/d ± CNI，2 週後開始慢減，總療程常 >1 年 | 加 MMF 等第二藥未改善 first-line |
| Ruxolitinib | 10 mg BID | REACH3：W24 ORR 50% vs 26%（BAT）；FDA 2021 |
| Belumosudil | 200 mg QD（ROCK2） | ROCKstar（≥2 線後）ORR 約 75%；FDA 2021 |
| Ibrutinib | 420 mg QD | ≥1 線後，ORR 67%；FDA 2017 |
| Axatilimab | 0.3 mg/kg q2w（CSF-1R） | AGAVE-201（≥2 線後）；FDA 2024 |
| ECP | 每 1–2 週連 2 天，≥3–6 個月評估 | 皮膚、口、肝較好；類固醇節省 |
| 其他 | Sirolimus、MMF、rituximab、imatinib（硬皮）、low-dose IL-2 | 中心經驗 |

## 破題關鍵句

| 題 | 一開口就講 |
| --- | --- |
| 診斷 | 「我不用 D+100 切，我找 NIH diagnostic sign；只有 distinctive 就要切片或檢查佐證。」 |
| 治療強度 | 「先算 8 器官 score 定 global severity：mild 局部、moderate–severe 才全身類固醇。」 |
| SR 二線 | 「看卡在哪一期：發炎 rux，B cell ibrutinib，纖維化 belumosudil／axatilimab。」 |

## 容易被電

- 肺 score 1 就已是 moderate、肺 score 2 就是 severe：肺不能算進 mild。
- 單獨乾眼、口乾、指甲變化是 distinctive，不足以診斷。
- 只顧全身藥、沒講眼科、牙科、PT、婦科：纖維化不會被免疫抑制逆轉。
- 忘了 cGVHD 病人是功能性無脾：包膜菌（肺炎鏈球菌）敗血症會致死。
- Ruxolitinib／azole 合用：posaconazole／voriconazole 是 CYP3A4 抑制，rux 要減量。
