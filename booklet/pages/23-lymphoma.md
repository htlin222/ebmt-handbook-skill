<div class="fp"><b>第一性原理</b>　三種細胞治療的藥效來源互不重疊：<b>auto</b>＝高劑量化療（只對 <b>chemosensitive</b> 病有用，沒有 GVL）；<b>allo</b>＝GVL（化療抗藥但<b>免疫敏感</b>的病也有效，代價 NRM 15–25%）；<b>CAR-T</b>＝工程化 T cell（不需要化療敏感、無 GVHD）。<b>復發時間</b>是化療敏感度的代理指標：早期復發／refractory＝化療抗藥 → auto 會輸。所以每個淋巴瘤只問三題：還對化療敏感嗎、多早復發、這個病有沒有 GVL（FL、MCL、CLL、HL 強；DLBCL 弱；Burkitt 幾乎沒有）。</div>

## MECE 分岔

| 層 | 問什麼 | 分支（互斥、窮盡） | 決定了什麼 |
| --- | --- | --- | --- |
| 1 | 化療敏感度（以復發時間代理） | Primary refractory 或 ≤12 個月復發 ／ >12 個月復發且 salvage 有反應 ／ salvage 無反應 | 第二支 → salvage＋auto；第一、三支 → CAR-T（LBCL）或新藥 |
| 2 | 已用過哪個細胞治療 | 都沒用過 ／ auto 後復發 ／ CAR-T 後復發 | Auto 後 → CAR-T 或 allo；CAR-T 後 → bispecific、allo（需 GVL） |
| 3 | 這病的 GVL 強度 | 強（FL、MCL、CLL、HL、PTCL）／ 弱（DLBCL、Burkitt） | 強 → allo 是合理晚期選項；弱 → allo 只在 CR 時才有意義 |
| 4 | CR1 是否鞏固 | 不需要（化療治癒率高）／ CR1 auto（高復發組織型）／ CR1 allo（極高危） | ALCL ALK+ 不移植；PTCL-NOS、AITL、MCL 年輕 → auto；HSTCL、aggressive ATLL → allo |

## 速記：各組織型

| 病 | 移植位置 | 關鍵試驗／數字 |
| --- | --- | --- |
| DLBCL 晚復發（>12 月） | Salvage（R-ICE、R-DHAP）→ 化療敏感 → auto（BEAM） | PARMA：5 年 EFS 46% vs 12%；CORAL：<12 個月復發 3 年 EFS 約 20% |
| DLBCL 早復發／refractory | 二線 CAR-T 取代 salvage＋auto | ZUMA-7（axi-cel，EFS 8.3 vs 2.0 月，OS 獲益）、TRANSFORM（liso-cel）；BELINDA（tisa-cel）陰性 |
| DLBCL 三線以上 | CAR-T（ZUMA-1、JULIET、TRANSCEND）或 bispecific；失敗且 CR → allo | 不適合移植的二線：PILOT（liso-cel） |
| PCNSL | CR1 thiotepa-based auto 鞏固 | IELSG32 |
| HL 復發 | Salvage（含 PD-1 組合可提高 PET-CR）→ auto；移植前 PET 陰性預後最好 | 高危（primary refractory、<12 月復發、結外復發）auto 後 BV 鞏固：AETHERA 5 年 PFS 59% vs 41% |
| HL auto 後復發 | BV、PD-1 → allo（RIC，優先 PTCy） | PD-1 後 allo：hyperacute GVHD、非感染發燒 → 間隔越長越好 |
| FL | POD24 早期復發且化療敏感 → auto；多次復發或 auto 後 → allo（GVL 強、復發低） | CAR-T ≥3 線：ZUMA-5、ELARA；轉化 FL 照 DLBCL |
| MCL 年輕 CR1 | 傳統：cytarabine 誘導＋auto＋rituximab 維持（LyMa） | TRIANGLE：加 ibrutinib 後 auto 未顯優勢 → CR1 auto 爭議；TP53 突變 auto 無益 |
| MCL 復發 | BTKi 後 → brexu-cel（ZUMA-2，ORR 約 90%）；之後 allo | Pirtobrutinib 為橋接 |
| CLL | Allo 只留給 BTKi＋BCL2i 雙重失敗（尤其 TP53）、Richter 緩解後 | Liso-cel（TRANSCEND CLL 004）同位置；RIC |
| PTCL | ALCL ALK+ CR1 不移植；PTCL-NOS、AITL、ALK− ALCL、EATL → CR1 auto；復發化療敏感 → allo | NLG-T-01：CR1 auto 5 年 PFS 44%；ECHELON-2（BV-CHP） |
| HSTCL、aggressive ATLL（acute／lymphoma type） | CR1 allo（auto 無效） | 化療後極早復發，靠 GVL |
| Burkitt | 一線化療治癒率高、復發幾乎化療抗藥 → 移植角色極小 | 復發後即使 auto／allo 長期存活低 |
| NKTCL | Asparaginase-based（SMILE、P-GemOx、DDGP）＋RT；晚期 CR1 auto 可考慮；復發 → allo | 移植前 EBV DNA 陰性預後好；PD-1 有效 |
| HIV 淋巴瘤 | HIV 不是禁忌：auto 結果同 HIV 陰性（BMT CTN 0803） | 避開 ritonavir／cobicistat（CYP3A4），改 integrase inhibitor；CCR5Δ32 donor allo 曾治癒 HIV |

## 破題關鍵句

| 題 | 一開口就講 |
| --- | --- |
| 淋巴瘤要哪種細胞治療 | 「先問化療敏感度（用復發時間代理），再問 GVL：敏感 → auto；抗藥 → CAR-T；需要 GVL → allo。」 |
| DLBCL 復發 | 「12 個月內或 refractory → 二線 CAR-T（ZUMA-7、TRANSFORM）；晚復發仍 salvage＋auto。」 |
| HL | 「化療敏感 → auto，高危加 BV（AETHERA）；auto 失敗 → PD-1 後 allo 用 PTCy。」 |
| CLL | 「BTKi、BCL2i 雙重失敗才談 allo 或 liso-cel。」 |

## 容易被電

- 說 ZUMA-7 是 axi-cel 在 ≥2 線後：是二線、primary refractory 或 12 個月內復發。
- 化療抗藥還送 auto：auto 沒 GVL，抗藥就輸（PARMA 收的是 chemosensitive）。
- ALCL ALK+ CR1 做 auto：預後好，不需要。
- PD-1 後馬上 allo 用傳統 GVHD 預防：hyperacute GVHD；用 PTCy、拉長間隔。
- 把 TRIANGLE 講成「auto 被淘汰」：結論是 ibrutinib 加入後 auto 的額外獲益不明，非所有人都不做。
- HIV 陽性就排除移植：cART 控制下 auto 結果相同，注意 DDI。
