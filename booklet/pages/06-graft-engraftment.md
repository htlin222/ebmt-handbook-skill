<div class="fp"><b>第一性原理</b>　植入要三件事同時成立：<b>種子</b>（活的 HSC 數量足夠）、<b>土壤</b>（niche 沒被纖維化、病毒、藥物破壞）、<b>沒有人拔苗</b>（殘存宿主 T／NK cell 與 DSA 不排斥 graft）。Chimerism 是分辨這三者的鑰匙：<b>血球低＋宿主細胞回來＝被排斥（graft failure）</b>；<b>血球低＋全是 donor＝種子或土壤出問題（poor graft function）</b>。Graft 操作（T-cell depletion、冷凍）都是在調整袋子裡的細胞組成，用 GVHD 減少換取 rejection、感染與 relapse 增加。</div>

## MECE 分岔一：血球沒起來（或掉下來）時，先問 chimerism

| 層 | 問什麼 | 分支（互斥、窮盡） | 下一步 |
| --- | --- | --- | --- |
| 1 時間 | 有沒有植入過？ | 從未達 ANC ≥0.5（D+28；cord D+42）＝primary／植入後再掉＝secondary | 定義 graft failure 類型 |
| 2 Chimerism | 造血是誰的？ | Donor 喪失（宿主 autologous recovery 或 aplasia）＝graft failure／donor ≥95% 但 ≥2 系血球低＝poor graft function（PGF） | GF → 第二次移植；PGF → 找原因＋CD34 boost |
| 3 GF 機轉 | 誰拔的苗？ | 細胞性（殘存宿主 T／NK：RIC、mismatch、TCD）／抗體性（DSA） | 第二次移植的 conditioning 加強免疫抑制；DSA 要換 donor 或 desensitize |
| 4 PGF 機轉 | 種子還是土壤？ | 種子（CD34 低、cord、冷凍損傷）／土壤（CMV、HHV-6、B19、ganciclovir、MMF、TMP-SMX、GVHD、MF 纖維化、敗血症） | 先移除可逆原因，再 boost |
| 5 惡性疾病 | 宿主細胞是正常還是腫瘤？ | 正常宿主造血（rejection）／腫瘤回來（relapse，看 CD34⁺ 或 blast 的 chimerism＋MRD） | Relapse 走 17 頁 |

## 速記：定義（EBMT）

| 名詞 | 定義 |
| --- | --- |
| Neutrophil engraftment | 連續 3 天 ANC ≥0.5 ×10⁹/L 的第一天 |
| Platelet engraftment | 不輸血下 PLT ≥20 ×10⁹/L 連續 7 天的第一天（部分用 ≥50） |
| Primary GF | D+28 未達 ANC ≥0.5（cord D+42），donor chimerism <5%（或無 donor 造血） |
| Secondary GF | 植入後 ANC 再 <0.5，且失去 donor chimerism |
| PGF | ≥2 系血球低（ANC <1.0、PLT <30 或 Hb <10 g/dL／輸血依賴）持續 ≥2 週、D+28 後，骨髓低細胞、donor >95%，排除復發與重度 GVHD |
| Complete／mixed／split | Donor ≥95%／5–95%／各 lineage 不同（例：myeloid donor、T cell mixed） |

## 速記：Chimerism 怎麼驗、怎麼讀

| 項目 | 重點 |
| --- | --- |
| 方法 | STR-PCR（敏感度 1–5%，標準）、qPCR／ddPCR（indel／SNP，~0.1%）、NGS；性別不合可用 XY-FISH |
| CD3⁺ T cell | 預測 rejection：RIC 後早期 T-cell donor <50% → GF 風險 |
| CD33／CD34⁺ | 預測 relapse：比全血敏感 |
| 時間點 | D+30、D+100、之後依風險（RIC、MDS／AML 更密） |
| 惡性：donor 下降 | Relapse 或 rejection → 減停 IS、DLI（見 17 頁） |
| 非惡性：穩定 mixed | 可接受；SCD 約 20% donor myeloid 即可無症狀 |

## 速記：Graft 處理（Ch.19–20）

| 項目 | 數字／重點 |
| --- | --- |
| CD34 計數 | ISHAGE single-platform 流式＋7-AAD 存活＋counting beads |
| 劑量 | Auto ≥2 ×10⁶/kg；allo PBSC 4–8 ×10⁶/kg；BM TNC ≥3 ×10⁸/kg；cord 見 04 頁 |
| 冷凍 | DMSO 5–10%、控速 −1～−2°C/min、液態氮氣相 ≤−150°C；37°C 水浴快速解凍 |
| DMSO 毒性 | 噁心、蒜味、心搏過緩、過敏樣；~1 g/kg/d 為限 |
| Fresh allo | 2–8°C 保存，採集後 ≤72 小時內輸注；冷凍 allo 可行但植入稍慢 |
| ABO 處理 | Major mismatch → 去紅血球；minor → 去血漿 |

## MECE 分岔二：Ex vivo T-cell depletion 平台（Ch.19）

| 平台 | 移除／保留 | 特點 |
| --- | --- | --- |
| CD34⁺ positive selection | 只留 CD34（T cell <1–5 ×10⁴/kg） | GVHD 最少；感染、GF、relapse ↑；BMT CTN 1301 無 CRFS 優勢、NRM 較高 |
| TCRαβ／CD19 depletion | 去 αβ T＋B；留 NK、γδ T、HSC | 兒童 haplo 主力；B 去除降 EBV-PTLD |
| CD45RA depletion | 去 naive T；留 memory T | 保留病毒免疫，常作 DLI／add-back |

## 速記：處理 GF／PGF／DSA（Ch.41）

| 情境 | 處理 |
| --- | --- |
| GF | 第二次移植，越快越好；常換 donor；免疫抑制型 conditioning（Flu／Cy／ATG ± TBI 2 Gy）；G-CSF 只是支持 |
| PGF | 停骨髓毒性藥、治病毒；同 donor CD34⁺-selected boost（不需 conditioning）；TPO-RA（eltrombopag） |
| DSA | 先換 donor；不行則 PLEX、IVIG、rituximab、bortezomib、含 donor HLA 的血小板或 buffy coat 吸附；目標 MFI <2,000 或 C1q 轉陰（依中心） |

## 破題關鍵句

| 題 | 一開口就講 |
| --- | --- |
| D+28 沒植入 | 「先驗 chimerism 分 graft failure 與 poor graft function，同時查 DSA、病毒、藥物、骨髓。」 |
| Mixed chimerism | 「看哪個 lineage、趨勢與疾病：T cell 下降怕 rejection，CD34 下降怕 relapse。」 |
| TCD | 「ex vivo TCD 用 GVHD 換感染、GF、relapse；αβ-TCD 保留 NK 與 γδ T。」 |

## 容易被電

- 植入失敗就打 G-CSF 等：GF 的本體是 rejection，要第二次移植。
- 把 PGF 當 GF：PGF 是全 donor，不需 conditioning，CD34 boost 即可。
- 只驗全血 chimerism：T-cell 與 CD34 分群更早、更敏感。
- 非惡性病人看到 mixed chimerism 就 DLI：穩定 MC 可能已足夠，DLI 只增加 GVHD。
- 忽略 DSA：haplo／cord 的經產婦受者是高危，要在 donor 選擇階段處理（見 04 頁）。
