<div class="fp"><b>第一性原理</b>　Conditioning 同時負責<b>（1）殺腫瘤</b>（烷化劑與 TBI 有陡峭的劑量反應）、<b>（2）壓宿主免疫</b>（不壓就 rejection）、<b>（3）騰出 niche</b>（讓 donor HSC 取代宿主造血）。強度的本質是「沒有 HSC 回輸，骨髓還能不能自己長回來」：MAC＝不可逆 aplasia、必須靠 graft；NMA＝幾乎不抑制骨髓、主要是免疫抑制；RIC 介於中間。強度越高 relapse 越低、NRM 越高，RIC 能成立是因為 GVL 補上了少殺的那部分腫瘤。</div>

## MECE 分岔：這個病人的 conditioning 主要在做哪件事

| 層 | 問什麼 | 分支（互斥、窮盡） | 決定了什麼 |
| --- | --- | --- | --- |
| 1 疾病性質 | 要殺的是腫瘤嗎？ | 惡性（需殺腫瘤＋GVL）／非惡性骨髓衰竭（SAA：只需免疫抑制）／非惡性遺傳疾病（thal、SCD、IEM：需騰 niche＋免疫抑制） | 惡性 → MAC／RIC 光譜；SAA → Cy＋ATG（±Flu、低劑量 TBI）；hemoglobinopathy → Bu 或 Treo 為主＋ATG |
| 2 疾病負荷 | 剩多少腫瘤？ | MRD⁻ CR／MRD⁺ CR／active disease | MRD⁺ 傾向 MAC（BMT CTN 0901）；active → 考慮 sequential（FLAMSA） |
| 3 病人耐受 | 扛得住多少？ | 年輕、HCT-CI 低 → MAC／年長或 HCT-CI 高 → RIC／很虛弱 → NMA | 見 03 頁 |
| 4 Rejection | HvG 壓力有多大？ | 低（MSD、惡性、近期化療）／高（mismatch、cord、heavily transfused SAA、DSA、MF） | 高 → 加 Flu／ATG／低劑量 TBI 等免疫抑制成分 |
| 5 器官與藥 | 哪個毒性不能碰？ | 肺（避 TBI、BCNU）／肝（避高 AUC Bu → SOS）／腎（調 Flu、Mel）／心（避高劑量 Cy） | 方案替換 |

## 速記：強度的操作定義（CIBMTR／Bacigalupo 2009）

| 類別 | 切點 | 代表 |
| --- | --- | --- |
| MAC | TBI ≥5 Gy 單次或 ≥8 Gy 分次；Bu >8 mg/kg PO（>6.4 mg/kg IV）；Mel >140–150 mg/m² | Bu/Cy、Cy/TBI 12 Gy、Flu/Bu4 |
| RIC | TBI <5 Gy 單次／<8 Gy 分次、Bu ≤8 mg/kg PO、Mel ≤140–150 mg/m²、thiotepa ≤10 mg/kg；仍需 graft 支持 | Flu/Bu2、Flu/Mel140、Flu/Treo |
| NMA | 不需 HSC 支持也會自己恢復 | TBI 2 Gy ± Flu（Seattle）、Flu/Cy、Flu/Cy/TBI 2 Gy（Baltimore haplo） |

## 速記：關鍵試驗

| 試驗 | 結論 |
| --- | --- |
| BMT CTN 0901（AML/MDS） | MAC vs RIC：MAC relapse 低、RFS 佳，提早終止；MRD⁺ 獲益最大 |
| Bornhäuser 2012（AML CR1） | Flu/TBI 8 Gy vs Cy/TBI 12 Gy：relapse、OS 相近 |
| Beelen 2020（AML/MDS 高齡） | Flu/Treo vs Flu/Bu2：Treo OS 較佳 |
| FORUM（兒童 ALL ≥4 歲） | TBI/etoposide 優於 chemo-only，ALL 要 TBI |
| TCI score（EBMT 2020） | 依藥物劑量加總分 low／intermediate／high，補 MAC／RIC 二分之不足 |

## 速記：常見方案

| 方案 | 劑量 | 用途 |
| --- | --- | --- |
| Bu/Cy（BuCy2） | Bu IV 3.2 mg/kg/d × 4（12.8 mg/kg；PO 16 mg/kg）＋Cy 60 mg/kg × 2 | MAC 髓系；SOS 較多（Cy 在 Bu 後） |
| Cy/TBI | Cy 60 mg/kg × 2＋TBI 12 Gy（2 Gy bid × 3 天）或 13.2 Gy | ALL 首選、MAC |
| Flu/Bu4、Flu/Bu2 | Flu ~150–160 mg/m²＋Bu IV 3.2 mg/kg/d × 4（MAC）或 × 2（RIC） | 髓系主流；Bu 天數決定強度 |
| Flu/Mel | Flu 150 mg/m²＋Mel 140 mg/m²（FM100 為減量） | RIC；黏膜炎、腎 |
| Flu/Treo | Treo 10–14 g/m² × 3＋Flu 150 mg/m² | 高齡髓系、兒童非惡性；SOS 少 |
| TBF | Thiotepa＋Bu＋Flu | Haplo、cord |
| Cy＋ATG | Cy 50 mg/kg × 4（200 mg/kg）＋ATG | SAA MSD；FA 大幅減 Cy |
| BEAM（auto） | BCNU 300 mg/m²、etoposide、Ara-C、Mel 140 mg/m² | Lymphoma；BCNU 肺毒性 |
| Mel200（auto） | Mel 200 mg/m²；CrCl <30–60 或高齡用 140 | MM |
| TT-BCNU（auto） | Thiotepa＋BCNU（或 Bu） | PCNSL（穿 BBB） |

## 速記：Bu TDM、TBI 與毒性

| 項目 | 重點 |
| --- | --- |
| Bu TDM | 目標 cumulative AUC 約 80–100 mg·h/L（~20,000 μM·min，依方案）；首劑量測、後續調整 |
| Bu 交互作用 | Levetiracetam 防癲癇（phenytoin 會誘導 Bu 代謝）；metronidazole、azole、acetaminophen 升 Bu |
| TBI 分次 | 12 Gy／6 次或 13.2 Gy／8 次；分次＋低劑量率＋肺 shielding（≤8–10 Gy）→ IPS、白內障少 |
| Cy | 出血性膀胱炎（acrolein → mesna＋水化）、心毒性、SIADH |
| Bu | 癲癇、SOS、IPS、色素沉著 |
| TBI | IPS、白內障、甲狀腺、生長、不孕、次發癌 |
| Mel／Flu／BCNU／TT | 黏膜炎＋腎／神經毒（腎調整）／延遲性肺炎（DLCO）／皮膚（勤洗澡） |

## 破題關鍵句

| 題 | 一開口就講 |
| --- | --- |
| MAC vs RIC | 「強度是 relapse 與 NRM 的交換；年輕 fit、MRD⁺ 傾向 MAC，年長 comorbid 用 RIC 靠 GVL。」 |
| 定義 | 「MAC 是不回輸 HSC 就不會恢復；用 CIBMTR 劑量切點：TBI ≥5 單次／≥8 分次、Bu >8 PO。」 |
| SAA 為何不 MAC | 「SAA 沒有腫瘤要殺，conditioning 只需壓免疫，Cy＋ATG 就夠。」 |

## 容易被電

- 把 RIC 當「比較安全的 MAC」：RIC relapse 較高，MRD⁺ AML 的 BMT CTN 0901 結果是 MAC 較好。
- Bu 不測濃度、用 phenytoin 防癲癇：AUC 高 → SOS，phenytoin 誘導 CYP 改變 Bu 濃度。
- ALL 不用 TBI：FORUM 顯示兒童 ALL TBI 較佳，成人也以 TBI-based 為主流。
- Fanconi anemia 照常規 Cy：DNA repair 缺陷，標準劑量會致命。
- Mel200 不看腎功能：腎差要降到 140，否則黏膜炎與 NRM 上升。
