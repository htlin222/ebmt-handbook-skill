<div class="fp"><b>第一性原理</b>　Conditioning（化療／TBI）、<b>CNI／mTORi</b>、植入期細胞激素、感染與 GVHD 都在<b>傷血管內皮</b>；內皮受傷只會走兩條路——<b>漏</b>（通透性上升 → 水腫、積液、出血）或<b>塞</b>（促凝、補體活化 → 微血栓）。症候群的名字只取決於<b>哪個血管床先壞</b>：肝竇 → SOS/VOD、腎小球 → TA-TMA、全身微血管 → ES／CLS、肺泡 → DAH、後腦 → PRES。所以處理永遠是「移除傷內皮的因子＋支持該器官＋針對下游路徑（defibrotide、complement blockade）」。</div>

## MECE 分岔：先問血管床，再問漏還是塞

| 血管床 | 症候群 | 主路徑 | 時間 | 診斷錨點 | 第一步處理 |
| --- | --- | --- | --- | --- | --- |
| 肝竇（zone 3） | SOS/VOD | 塞：竇內皮剝落、竇後阻塞 → 門脈高壓 | 多 ≤D+21；late onset 可 >21 天 | 黃疸＋痛性肝腫大＋體重↑／腹水；Doppler 反向門脈血流 | Defibrotide、利尿、限水 |
| 腎小球／全身小動脈 | TA-TMA | 塞：補體（C5b-9）介導微血栓 | 多 D+30–100 | 新發 LDH↑、血小板↓、schistocytes、蛋白尿、高血壓 | 處理誘因、控血壓、eculizumab |
| 全身微血管 | Engraftment syndrome（ES） | 漏：中性球恢復時細胞激素 | ANC 恢復前後 96 h | 非感染發燒＋紅疹＋肺浸潤／水腫 | 短程 methylprednisolone 1 mg/kg |
| 全身微血管 | Capillary leak syndrome（CLS） | 漏：G-CSF、細胞激素 | 早期 | 體重↑、水腫、低白蛋白、低血壓 | 支持、停 G-CSF、慎用輸液 |
| 肺泡微血管 | DAH | 漏＋出血 | 多 D+30 內 | BAL 灌洗液逐管更紅、≥20% hemosiderin-laden macrophages | 高劑量 steroid；排除感染 |
| 後循環腦血管 | PRES | 漏：自調失衡 → vasogenic edema | 任何時候，CNI 相關 | 頭痛、抽搐、皮質盲＋MRI 頂枕 T2／FLAIR 白質水腫 | 停／換 CNI、降血壓、補 Mg、抗癲癇 |

## SOS/VOD 診斷：EBMT 2016 成人 vs 2018 兒童

| 標準 | 內容 |
| --- | --- |
| 成人 classical（≤21 天） | Bilirubin ≥2 mg/dL＋以下 ≥2：痛性肝腫大、體重增加 >5%、腹水 |
| 成人 late onset（>21 天） | Classical 條件，或病理證實，或上述 ≥2 項＋超音波／血行動力學證據（HVPG ≥10 mmHg） |
| 兒童 2018（無時間限制） | ≥2 項：輸血難治的消耗性血小板低下、3 天連續體重↑或 >5%、肝腫大、腹水、bilirubin 連 3 天上升或 72 h 內 ≥2 mg/dL；<b>不強制黃疸</b> |

## 速記：SOS 危險因子、藥物；TA-TMA 診斷

| 主題 | 內容 |
| --- | --- |
| SOS 病人因子 | 既有肝病／肝纖維化、鐵過載、<b>gemtuzumab／inotuzumab</b> 前曝露、第二次移植、thalassemia、osteopetrosis、HLH、低 KPS |
| SOS 移植因子 | MAC（尤其 Bu 未做 TDM、Bu-Cy 順序）、TBI ≥12 Gy、MUD／mismatch、sirolimus＋tacrolimus |
| 預防 | Ursodiol（UDCA，約 12–15 mg/kg/d 至 ~D+90，依中心）；defibrotide 預防兒童高危 RCT 陽性（Corbacioglu 2012），成人 HARMONY 陰性 |
| 治療 | <b>Defibrotide 6.25 mg/kg q6h（25 mg/kg/d），≥21 天</b>至緩解；早用效果好；禁忌活動性出血、抗凝；severe／very severe 不等確診就給 |
| TA-TMA：Jodele 2014 | LDH↑、蛋白尿 ≥30 mg/dL、高血壓、新發血小板↓、貧血、schistocytes、sC5b-9↑；≥4 項或病理 → 診斷；<b>蛋白尿＋sC5b-9↑＝高危</b> |
| TA-TMA：2023 harmonized | 病理證實，或 7 項中 ≥4（14 天內、連兩次）；高危：sC5b-9↑、UPCR ≥1 mg/mg、器官功能異常、合併 aGVHD／感染 |
| TA-TMA 治療 | 治誘因（GVHD、感染）；CNI 停或換依嚴重度個別化；<b>eculizumab</b>（依藥動調劑量）；ADAMTS13 正常 → <b>plasma exchange 無效</b> |

## 出血、血栓、ES 細節

| 情境 | 處置 |
| --- | --- |
| 預防性血小板 | <10×10⁹/L；發燒、出血、侵入性處置提高門檻 |
| CVC／DVT 抗凝 | 血小板 ≥50 全劑量 LMWH；25–50 半劑量；<25 暫停 |
| HC、DAH、GI 出血 | 不是單純血小板低 → 找器官原因（見 16 頁） |
| ES vs 感染 | ES 是排除診斷；血培養、停藥疹後才給 steroid |
| ES 診斷（Spitzer 2001） | 植入 96 h 內：3 major（非感染發燒 ≥38.3°C、非藥疹紅疹 >25% BSA、非心因性肺水腫／缺氧），或 2 major＋≥1 minor（肝、腎、體重 ≥2.5%、短暫腦病變） |
| Pre-engraftment（cord） | 植入前即出現同樣表現，cord 最常見，多對 steroid 反應佳 |

## 破題關鍵句

| 題 | 一開口就講 |
| --- | --- |
| 任何早期多器官水腫／溶血 | 「這是內皮病：我先分血管床——肝竇、腎小球、肺泡、全身微血管、後腦——再分漏還是塞。」 |
| SOS/VOD | 「EBMT 2016 成人要 bilirubin ≥2 加兩項；兒童 2018 不需黃疸。一懷疑就分級、盡早 defibrotide。」 |
| TA-TMA | 「它不是 TTP：ADAMTS13 正常、補體驅動，PE 無效；高危就上 eculizumab。」 |

## 容易被電

- 用成人標準排除兒童 SOS：兒童可無黃疸，輸血難治血小板低下是線索。
- TA-TMA 當 TTP 做 plasma exchange：ADAMTS13 >10%，補體才是靶點。
- 以為 TA-TMA 一律停 CNI 就好：誘因多元（GVHD、感染、TBI），停 CNI 也可能誘發 GVHD。
- PRES 只想到 CNI：高血壓、低 Mg、輸液過多也是誘因；頭痛＋抽搐要先量血壓。
- DAH 當出血就輸血小板了事：是內皮損傷，需高劑量 steroid 並排除感染。
