<div class="fp"><b>第一性原理</b>　復發＝<b>躲過 conditioning 的腫瘤細胞長得比 GVL 殺得快</b>。腫瘤負荷是連續變數，在形態學復發之前就能量到（MRD），而任何免疫或標靶介入的效果都與負荷成反比 → 策略只有一條軸：<b>越早偵測、越早介入</b>（maintenance ＞ preemptive ＞ therapeutic）。失敗時問<b>腫瘤怎麼躲 T cell</b>：看不見（HLA loss）、看得少（downregulation）、被壓住（抑制微環境）→ 換 donor、補訊號、解煞車。</div>

## MECE 分岔

| 層 | 問什麼 | 分支（互斥、窮盡） | 決定了什麼 |
| --- | --- | --- | --- |
| 1 疾病負荷 | 現在在哪一階？ | 無可測疾病 ／ MRD+ 或 chimerism 下降 ／ 血液學復發 | Maintenance・prophylactic DLI ／ preemptive（減 IS、DLI、HMA）／ therapeutic（再誘導＋DLI 或 2nd HCT） |
| 2 有無專一標記 | 能直接量腫瘤嗎？ | 有（fusion、NPM1、IG/TCR、LAIP）／ 無 | 有 → MRD 監測；無 → lineage-specific chimerism 當替代 |
| 3 有無可用標靶 | 腫瘤有 druggable lesion？ | FLT3-ITD ／ BCR-ABL1 ／ IDH1/2 ／ 無 | Sorafenib・gilteritinib ／ TKI ／ IDHi ／ HMA ± venetoclax |
| 4 逃脫機轉 | 為何 GVL 失效？ | HLA loss ／ HLA class II downregulation ／ 抑制微環境 | 換 donor ／ IFN-γ、HMA、避免同 donor DLI ／ checkpoint、減 IS |

## MRD 方法與敏感度

| 方法 | 靶 | 敏感度 | 要點 |
| --- | --- | --- | --- |
| MFC（8–10 色）／NGF | LAIP／DfN | 10⁻⁴／NGF 10⁻⁵–10⁻⁶ | 快；CD19 標靶後抗原轉移會漏 |
| RQ-PCR | Fusion transcripts、NPM1 | 10⁻⁴–10⁻⁶ | NPM1 最佳；WT1 不夠專一 |
| ASO-PCR／NGS | IG/TCR 重排、突變 | 10⁻⁵–10⁻⁶ | CHIP 突變（DNMT3A、TET2、ASXL1）不算 MRD |
| Chimerism STR-PCR ／ qPCR | 受者 vs donor 多型 | 1–5% ／ 0.1% | <b>非腫瘤專一</b>；CD34+／CD33+ 分選提高預測 |

## Chimerism 與 MRD 的關係

| 情境 | 解讀 |
| --- | --- |
| MRD+、chimerism 全 donor | 腫瘤殘存為主，chimerism 不夠敏感 |
| MRD−、mixed chimerism | 受者正常造血或 T cell 殘存；看 CD3 vs CD34+ 分項 |
| CD34+ host 上升 | 復發前兆 → preemptive |
| T-cell MC 為主 | Graft rejection 風險 > 復發（見 06 頁） |
| HLA loss 復發 | STR 可見 host 細胞；需 HLA-KMR／genomic HLA typing 確認 |

## Maintenance：先問有無靶點

| 情境 | 藥物 | 關鍵證據 |
| --- | --- | --- |
| FLT3-ITD AML | Sorafenib | <b>SORMAIN</b>（RFS 改善）、Xuan 2020（中國 RCT，OS 改善） |
| FLT3-ITD AML | Gilteritinib | <b>MORPHO</b>：整體 RFS 未達顯著；<b>移植前後 MRD+ 次族群獲益</b> |
| Ph+ ALL | TKI（imatinib、dasatinib、ponatinib） | 預防性 vs MRD-triggered 皆可；多數至少 1 年 |
| 無靶點 AML／MDS | Azacitidine | RELAZA2（MRD-guided preemptive 有效）；固定劑量預防性 RCT（Oran 2020）陰性 |
| MM／HL／T-cell | Lenalidomide、BV、checkpoint | 個別化；checkpoint 後 GVHD 風險高 |

## DLI：三種情境與劑量（EBMT 共識）

| 項目 | 內容 |
| --- | --- |
| Prophylactic | 無疾病、高危（TCD、RIC、高危病）；低劑量起 |
| Preemptive | MRD+ 或 chimerism 下降；效果最佳 |
| Therapeutic | 血液學復發；<b>先 cytoreduction</b>（HMA ± ven、化療）再 DLI |
| 起始劑量 | MSD 約 1×10⁶–10⁷ CD3+/kg；MUD 約 10⁵–10⁶（早期較低）；haplo 10⁵–10⁶；每 4–12 週無 GVHD 則升半 log |
| 前提／風險 | 無活動性 GVHD、停 IS；風險 GVHD、aplasia；<b>CML 慢性期反應 70–80%</b>、AML 15–30%、ALL <20% |

## 免疫逃脫三類與下一步

| 機轉 | 怎麼發生 | 對下一步的含義 |
| --- | --- | --- |
| HLA loss | 6p copy-neutral LOH 丟掉 <b>mismatched haplotype</b>；haplo 後復發約 1/3 | 同 donor DLI 無效 → 換不共用該 haplotype 的 donor |
| HLA class II downregulation | 表觀遺傳下調，非刪除 | IFN-γ 可回復；DLI 效果差 |
| 抑制微環境 | PD-L1 等 checkpoint ligands↑、Treg、代謝抑制 | Checkpoint inhibitor（GVHD 風險）、HMA、減 IS |

## 復發後選擇：時間、負荷、體能、GVHD

| 因子 | 好 | 差 |
| --- | --- | --- |
| 移植到復發 | >6 個月（尤其 >12 個月） | <6 個月：2nd HCT 難獲益 |
| 疾病狀態 | 達 CR／MRD− 再鞏固（DLI 或 2nd HCT） | 活動性疾病 |
| 路徑 | 減 IS → 標靶（FLT3i、IDHi、TKI）或 HMA＋ven、ALL 用 inotuzumab／blinatumomab／CAR-T → DLI 或 2nd HCT | 不適合者支持療法 |

## 破題關鍵句

| 題 | 一開口就講 |
| --- | --- |
| 復發預防 | 「GVL 效果和腫瘤負荷成反比，所以盡早看見（MRD）、盡早出手（maintenance、preemptive DLI）。」 |
| MRD vs chimerism | 「MRD 量腫瘤，chimerism 量 host 造血；有標記就用 MRD，沒有才用 lineage chimerism。」 |
| DLI 沒效 | 「先問逃脫：HLA loss 要換 donor，downregulation 要恢復表現，微環境要解煞車。」 |

## 容易被電

- 把 mixed chimerism 直接等同復發：可能是受者正常造血，要看分項與 MRD。
- HLA loss 復發還給同一 donor DLI：T cell 的靶不見了，必須換 donor。
- 血液學復發直接 DLI：高負荷下 DLI 幾乎無效，先 cytoreduction。
- 把 CHIP 突變（DNMT3A、TET2）當 AML MRD：不代表白血病殘存。
- 說 MORPHO 陽性：主要終點未達，只在 MRD+ 次族群看到 RFS 獲益。
