<div class="fp"><b>第一性原理</b>　移植期間病人同時失去五樣東西：<b>皮膚屏障</b>（CVC 打穿）、<b>黏膜屏障</b>（mucositis、GI GVHD → 吃不下、菌移位）、<b>造血</b>（要靠輸血，而輸進去的 donor/血品淋巴球與抗體會反過來攻擊）、<b>免疫</b>（環境病原變成致命）、<b>代謝餘裕</b>（CNI 治療窗窄、走 <b>CYP3A4／P-gp</b>，每加一個藥都改變濃度）。支持照護就是逐項暫代：每一項都問「缺什麼 → 補什麼 → 補的東西本身有什麼風險」。</div>

## MECE 分岔：缺哪一樣

| 失去的功能 | 暫代手段 | 補的東西帶來的風險 | 關鍵動作 |
| --- | --- | --- | --- |
| 皮膚屏障 | Tunneled CVC | CLABSI、血栓、阻塞 | 決定保留 vs 拔管 |
| 黏膜屏障 | 營養（EN 優先 → PN） | PN：CLABSI、肝膽汁滯留、高血糖 | 腸能用就用腸 |
| 造血 | 紅血球、血小板 | TA-GVHD、CMV、alloimmunization、ABO 溶血 | Irradiated＋leukoreduced；依 ABO 配型選血品 |
| 免疫 | 環境控制 | — | HEPA、手部衛生、隔離分級 |
| 代謝餘裕 | 藥物濃度監測 | DDI → CNI 中毒或 GVHD flare | 加／停 azole 時同步調 CNI |

## 速記：CVC

| 類型 | 特點 |
| --- | --- |
| Non-tunneled（CVC、apheresis） | 短期、感染率最高；apheresis 導管大孔徑供採集／ECP |
| Tunneled cuffed（Hickman／Broviac） | HCT 標準：多腔、可長期、cuff 擋細菌 |
| PICC | 周邊置放，血栓率較高 |
| Port | 全埋皮下，感染最低；需穿針，不適合密集多路輸注 |

| 併發症 | 判斷與處置 |
| --- | --- |
| 置放早期 | 氣胸、動脈誤穿、malposition、出血（超音波導引、血小板依中心門檻） |
| CLABSI | DTP：中心比周邊早 ≥2 h 陽性；CoNS 最常見，可試 lock therapy 保管 |
| 必拔管 | S. aureus、Pseudomonas、Candida、mycobacteria；tunnel／pocket 感染；septic shock；治療 72 h 仍菌血；化膿性血栓靜脈炎／心內膜炎 |
| 血栓 | LMWH；血小板 <50 減量、<20–25 停（依中心）；阻塞用 alteplase |

## 速記：輸血與 ABO

| 項目 | 規則 |
| --- | --- |
| 門檻 | RBC：Hb 7–8 g/dL；預防性 PLT <10×10⁹/L（發燒、出血、侵入性處置提高） |
| Irradiated | 細胞性血品（RBC、PLT、granulocyte）≥25 Gy 防 TA-GVHD；allo 從 conditioning 起，持續期間依 BSH／中心（常至停 IS 或終身） |
| Leukoreduced | 減 CMV 傳播（CMV-safe）、HLA alloimmunization、發燒反應 |
| PLT refractoriness | 1-h CCI 兩次 <5000：非免疫（發燒、sepsis、脾大、DIC、VOD）vs HLA 抗體 → HLA-matched 血小板 |

| ABO 類型（例） | 風險 | RBC | PLT／血漿 |
| --- | --- | --- | --- |
| Major（A → O 受者） | 輸注時溶血（BM 要去紅血球）、紅血球植入延遲、<b>PRCA</b>（anti-A 持續） | 受者型（O） | 捐者型（A）或 AB |
| Minor（O → A 受者） | <b>Passenger lymphocyte syndrome</b>：D+5–15 急性溶血（PBSC、無 MTX 較多）；graft 去血漿 | 捐者型（O） | 受者型（A）或 AB |
| Bidirectional（A ↔ B） | 兩者皆有 | O | AB |

## 速記：DDI（Ch.31）

| 機轉 | 藥物 | 動作 |
| --- | --- | --- |
| CYP3A4 抑制 ↑CNI／sirolimus | Voriconazole、posaconazole（強）、isavuconazole、fluconazole（中）、clarithromycin、diltiazem、letermovir | Vori／posa 起始 tacrolimus 減到約 1/3；CsA vori 減半、posa 減到 3/4；vori＋sirolimus 原則避免 |
| CYP3A4 誘導 ↓CNI | Rifampicin、carbamazepine、phenytoin、St John's wort | 換藥優先（levetiracetam 防 Bu 癲癇） |
| 停掉抑制劑 | 停 azole | CNI 掉 → GVHD flare，要追濃度 |
| 毒性相加 | 腎：CNI＋vanco、aminoglycoside、AmB、foscarnet；骨髓：GCV、MMF、TMP-SMX；QT：azole、FQ、ondansetron | 監測 Cr、CBC、ECG |
| 其他強抑制劑受害者 | Venetoclax、ruxolitinib、vincristine | 減量或避免 |

## 速記：營養與感控

| 項目 | 重點 |
| --- | --- |
| 篩檢 | NRS-2002 等每週；移植前體重減輕、BMI 低＝高風險 |
| 路徑 | EN 優先（較少感染、腸黏膜營養）；PN 給腸無法用時（重度 mucositis、ileus、grade III–IV GI GVHD）；口服不足數天即介入 |
| 量 | 熱量約 25–30 kcal/kg/d（依間接熱量）、蛋白 1.2–1.5 g/kg/d；補 Mg（CNI 流失） |
| 低菌飲食 | RCT 無效益 → 改「食品安全」（避生食、未殺菌乳品） |
| 環境 | HEPA＋正壓、≥12 次換氣／h → 防 Aspergillus；施工、植物、Legionella 水 |
| 手部衛生 | 最重要；C. difficile 要肥皂洗手（酒精不殺芽孢） |
| 隔離分級 | 接觸（MDRO、C. diff）／飛沫（流感、RSV）／空氣負壓（TB、VZV、麻疹） |

## 破題關鍵句

| 題 | 一開口就講 |
| --- | --- |
| CVC 發燒 | 「中心、周邊同時抽血看 DTP；S. aureus、Pseudomonas、Candida 或 tunnel 感染就拔。」 |
| ABO 不合 | 「先分 major／minor／bidirectional：major 怕 PRCA，minor 怕 D+5–15 passenger lymphocyte 溶血。」 |
| 加 azole | 「同一天減 CNI 並 2–3 天內追濃度；停 azole 時反向調。」 |

## 容易被電

- 以為 FFP、cryo 也要照射：只有細胞性血品要。
- ABO 不合會降低存活：主要影響溶血與紅血球植入，不是排除 donor 的理由。
- Minor ABO 只在輸注當下溶血：真正危險是 1–2 週後的 passenger lymphocyte syndrome。
- 低菌飲食是標準：證據不支持，重點是食品安全與手部衛生。
- 酒精乾洗手對 C. difficile 夠用：芽孢要肥皂洗手。
