## Chapter 57 — MRD 監測（ALL 和 AML） [書中驗證]

### ALL 的 MRD（Ch.57.1）
**方法**：
- 流式細胞術（MFC）：敏感度 10⁻⁴
- PCR（IG/TCR 重排）：敏感度 10⁻⁵
- NGS：敏感度 10⁻⁶（最高）

**移植後監測時間點**：D+30, D+60, D+100, 每3個月直到 D+2年

**臨床決策**：
- MRD 陰性 → 維持 CNI，觀察
- MRD 陽性/上升 → 考慮 DLI、停免疫抑制、挽救治療

### AML 的 MRD（Ch.57.2）
**標記物**：NPM1、FLT3-ITD、RUNX1-RUNX1T1、CBFB-MYH11、WT1

**決策**：
- NPM1 MRD+（移植後）→ DLI 或 Azacitidine 維持

## Chapter 58 — 藥物預防與治療復發 [書中驗證]

**TKI（BCR-ABL）**（Ch.58.2）：
- Ph+ ALL / CML：移植後立即恢復 TKI
- Imatinib、Dasatinib（BBB 穿透）、Ponatinib（T315I 突變）

**FLT3 抑制劑**（Ch.58.3）：
- AML FLT3-ITD：移植後 Midostaurin 或 Sorafenib 維持
- SORMAIN 試驗：Sorafenib 維持改善 RFS

**去甲基化藥物（HMA）**（Ch.58.5）：
- Azacitidine：MDS/AML 移植後維持（RELAZA2 試驗）
- 機制：免疫調節 + 分化誘導

**BCL-2 抑制劑**（Ch.58.10）：
- Venetoclax：AML 復發後，與 HMA 或低劑量化療合併

**免疫檢查點抑制劑**（Ch.58.4）：
- PD-1/PD-L1：移植後使用需謹慎，GVHD 風險高
- Hodgkin 淋巴瘤：移植後 Pembrolizumab / Nivolumab

## Chapter 59 — DLI（供者淋巴球輸注） [書中驗證]

**機制**（Ch.59.1）：GVL（移植物抗白血病效應）

**適應症**（Ch.59.2）：
- 預防性（prophylactic）：高風險，MRD 陽性
- 搶先性（preemptive）：MRD 上升或 MC 下降
- 治療性（therapeutic）：明顯復發

**劑量原則**（Ch.59.2）：
| 情境 | 起始劑量 |
|-----|---------|
| CML | 1×10⁷ CD3+/kg → 緩慢升級 |
| AML/ALL | 1×10⁷ ~ 1×10⁸ CD3+/kg |
| GVHD 低風險（如 MAC + MSD）| 更高劑量 |

**禁忌**：
- 活動性 aGVHD
- 正在使用高劑量免疫抑制

**主要副作用**：GVHD（皮膚、肝、腸）、骨髓抑制

## Chapter 60 — CAR-T 細胞療法 [書中驗證]

**原理**（Ch.60.3）：
- 患者 T 細胞體外工程化 → 表達 CAR（嵌合抗原受體）
- 常見靶點：CD19（B-ALL/淋巴瘤）、BCMA（骨髓瘤）、CD22

**已核准 CAR-T 產品**（截至 2024）：

| 產品 | 靶點 | 適應症 |
|-----|------|-------|
| Tisagenlecleucel（Kymriah）| CD19 | B-ALL（<25歲）、DLBCL |
| Axicabtagene ciloleucel（Yescarta）| CD19 | DLBCL、FL |
| Lisocabtagene maraleucel（Breyanzi）| CD19 | DLBCL、CLL |
| Idecabtagene vicleucel（Abecma）| BCMA | MM |
| Ciltacabtagene autoleucel（Carvykti）| BCMA | MM |

**主要毒性**（Ch.60.3）：
- **CRS（細胞激素釋放症候群）**：
  - Grade 1：發燒
  - Grade 2：O2 需求 <40%，低血壓（補液有效）
  - Grade 3-4：O2 ≥40%, 昇壓藥需求
  - 治療：Tocilizumab 8mg/kg（優先）+ Dexamethasone
- **ICANS（神經毒性）**：
  - 評分：ICE score（方向感、命名、服從、書寫、注意力）
  - Grade 3-4 → Dexamethasone + 支持

**預淋巴清除（Lymphodepletion）**：
- Flu 30mg/m²/day x3天 + Cy 300-500mg/m²/day x3天

## Chapter 61 — 免疫抵抗機制（Immune Resistance）[模型補充]

**腫瘤逃脫免疫的機制**（Ch.61.2）：
1. **HLA 喪失**：腫瘤細胞下調或刪除 HLA → T 細胞看不到
2. **PD-L1 上調**：抑制 T 細胞活化（checkpoint pathway）
3. **抗原喪失**：CD19 喪失（→ CD19 CAR-T 失效）；見於 B-ALL 復發
4. **免疫抑制微環境**：調節 T 細胞（Tregs）、MDSCs

**臨床意義**：
- HLA 喪失 → DLI 無效（T 細胞找不到靶點）
- PD-L1 ↑ → Checkpoint inhibitor 有機會，但移植後 GVHD 風險
- CD19 喪失 → 需改 CD22 CAR-T 或 CD19/CD22 雙靶向

## Chapter 62 — ATMP 法規（Regulatory Aspects）[模型補充]

**ATMP（Advanced Therapy Medicinal Products）定義**：
- 基因治療產品（GTMPs）
- 體細胞治療產品（sCTMPs）：包括 CAR-T
- 組織工程產品（TEPs）

**與「最少操作」的區分**（Ch.62）：
- 最少操作（minimally manipulated）：CD34+ 選取、去除紅血球 → 不需 ATMP 許可
- 基因修改（CAR-T、基因編輯）→ 需 ATMP 完整法規批准
- 歐盟：EMA 的 CAT（Committee for Advanced Therapies）負責審查

**臨床影響**：ATMP 費用極高；保險給付與醫院資質要求嚴格
